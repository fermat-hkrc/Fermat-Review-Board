## 漏洞概述

`I400ToI420_wrapper` 的 C fallback 路径中，将 U 和 V 两个平面的大小之和 `UVCOMSize` 同时作为 `memset_s` 的 `destMax` 和 `count` 参数，从 `dest.planes[UCOM]`（U 平面起始地址）开始写入。这违反了 `memset_s` 的安全契约 — `destMax` 应为目标缓冲区的实际大小，而非期望写入的总量。当 U 和 V 平面非连续分配时，将导致堆缓冲区溢出。

## 问题代码

**文件**: `plugins/common/libs/image/libextplugin/src/jpeg_yuv_decoder/jpeg_yuvdata_converter.cpp`

```cpp
// Line 344-346
const uint8_t chromaValueForGray = 0x80;
uint32_t UVCOMSize = dest.planeWidth[UCOM] * dest.planeHeight[UCOM];
UVCOMSize += dest.planeWidth[VCOM] * dest.planeHeight[VCOM];  // U+V 合计
errno_t ret = memset_s(dest.planes[UCOM], UVCOMSize, chromaValueForGray, UVCOMSize);
// ↑ 从 U 平面起始写入 U+V 合计大小，假设 U/V 连续但未验证
```

**正确做法**应分别对 U 和 V 平面执行 memset：

```cpp
uint32_t uSize = dest.planeWidth[UCOM] * dest.planeHeight[UCOM];
uint32_t vSize = dest.planeWidth[VCOM] * dest.planeHeight[VCOM];
memset_s(dest.planes[UCOM], uSize, chromaValueForGray, uSize);
memset_s(dest.planes[VCOM], vSize, chromaValueForGray, vSize);
```

## 触发条件

1. 系统未安装 `libyuv.z.so`（`YuvHelper::GetInstance().I400ToI420` 为 null），进入 C fallback 路径
2. 调用 `I400ToI420_wrapper` 时 `dest.planes[UCOM]` 和 `dest.planes[VCOM]` 为独立分配的缓冲区（非连续内存布局）
3. `memset_s` 从 U 平面起始写入 `U_size + V_size` 字节，超出 U 平面分配范围

当前生产代码中唯一调用者 `ConvertFromGray` 恰好使用连续 Y|U|V 布局，掩盖了此缺陷。但 `I400ToI420_wrapper` 是公共 API（header 中声明），接受任意 `YuvPlaneInfo` 参数，任何使用独立 U/V 分配的调用者都会触发溢出。

## 影响

- 堆缓冲区溢出（写入 U 平面分配大小的 2 倍数据）
- 进程崩溃（DoS）
- 潜在的内存破坏（覆盖相邻堆对象）
- 代码维护风险：任何重构改变 U/V 内存布局即暴露此 bug


## 修复建议

```diff
     const uint8_t chromaValueForGray = 0x80;
-    uint32_t UVCOMSize = dest.planeWidth[UCOM] * dest.planeHeight[UCOM];
-    UVCOMSize += dest.planeWidth[VCOM] * dest.planeHeight[VCOM];
-    errno_t ret = memset_s(dest.planes[UCOM], UVCOMSize, chromaValueForGray, UVCOMSize);
-    if (ret != EOK) {
-        return -1;
-    }
+    uint32_t uPlaneSize = dest.planeWidth[UCOM] * dest.planeHeight[UCOM];
+    uint32_t vPlaneSize = dest.planeWidth[VCOM] * dest.planeHeight[VCOM];
+    errno_t ret = memset_s(dest.planes[UCOM], uPlaneSize, chromaValueForGray, uPlaneSize);
+    if (ret != EOK) {
+        return -1;
+    }
+    ret = memset_s(dest.planes[VCOM], vPlaneSize, chromaValueForGray, vPlaneSize);
+    if (ret != EOK) {
+        return -1;
+    }
     return 0;
```
