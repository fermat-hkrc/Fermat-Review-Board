## 漏洞概述

`powermgr_powermgr_lite` 的 `AcquireInvoke()` 和 `ReleaseInvoke()` 函数从 IPC 请求中读取 `len`（uint32_t），直接传入 `ReadBuffer(req, len)` 获取数据指针，随后将该指针强制转换为 `RunningLockEntry*` 使用。两处均无任何校验：

1. 未检查 `len == sizeof(RunningLockEntry)`
2. 未检查 `ReadBuffer` 返回值是否为 NULL
3. 未检查 `len` 是否在合理范围内

攻击者通过 IPC 发送 `len` 值大于实际 payload 或与 `RunningLockEntry` 大小不匹配的消息，可触发堆/栈越界访问。

## 问题代码

**文件**: `services/src/power/small/power_manage_feature_impl.c`

```c
// Line 66-76 — AcquireInvoke
static int32_t AcquireInvoke(IServerProxy *iProxy, void *origin, IpcIo *req, IpcIo *reply)
{
    uint32_t len = 0;
    ReadUint32(req, &len);                          // ← 攻击者可控
    void *data = (void*)ReadBuffer(req, len);       // ← 无 NULL 检查
    int32_t timeoutMs = 0;
    ReadInt32(req, &timeoutMs);
    int32_t ret = OnAcquireRunningLockEntry((IUnknown *)iProxy,
        (RunningLockEntry *)data, timeoutMs);       // ← 直接解引用
    WriteInt32(reply, ret);
    return EC_SUCCESS;
}

// Line 78-86 — ReleaseInvoke（同样模式）
static int32_t ReleaseInvoke(IServerProxy *iProxy, void *origin, IpcIo *req, IpcIo *reply)
{
    uint32_t len = 0;
    ReadUint32(req, &len);                          // ← 攻击者可控
    void *data = (void*)ReadBuffer(req, len);       // ← 无 NULL 检查
    int32_t ret = OnReleaseRunningLockEntry((IUnknown *)iProxy,
        (RunningLockEntry *)data);                  // ← 直接解引用
    WriteInt32(reply, ret);
    return EC_SUCCESS;
}
```

IPC dispatch 入口：
```c
// Line 43-44

    AcquireInvoke,   // funcId = 0
    ReleaseInvoke,   // funcId = 1
    ...
};
```

## 触发条件

1. 恶意 IPC 客户端向 PowerMgr 服务发送消息，funcId = 0 或 1
2. 设置 `len` 为超大值（超出 IPC buffer 实际大小）
3. `ReadBuffer` 返回 NULL 或越界指针
4. `OnAcquireRunningLockEntry` / `OnReleaseRunningLockEntry` 解引用该指针时崩溃

## 影响

- 堆缓冲区越界读取（AcquireInvoke 触发 heap-buffer-overflow）
- 栈缓冲区越界读取（ReleaseInvoke 触发 stack-buffer-overflow）
- PowerMgr 服务进程崩溃（DoS）
- 潜在的信息泄露（越界读取的数据可能通过 reply 返回）

## 修复建议

```c
static int32_t AcquireInvoke(IServerProxy *iProxy, void *origin, IpcIo *req, IpcIo *reply)
{
    uint32_t len = 0;
    ReadUint32(req, &len);
+   if (len != sizeof(RunningLockEntry)) {
+       WriteInt32(reply, EC_INVALID);
+       return EC_FAILURE;
+   }
    void *data = (void*)ReadBuffer(req, len);
+   if (data == NULL) {
+       WriteInt32(reply, EC_INVALID);
+       return EC_FAILURE;
+   }
    int32_t timeoutMs = 0;
    ReadInt32(req, &timeoutMs);
    int32_t ret = OnAcquireRunningLockEntry((IUnknown *)iProxy, (RunningLockEntry *)data, timeoutMs);
    WriteInt32(reply, ret);
    return EC_SUCCESS;
}
```

对 `ReleaseInvoke` 做同样修改。
