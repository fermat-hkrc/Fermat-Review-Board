## 漏洞概述

`BundleFileUtils::MkOwnerDir` 先调用 `IsExistDir()` 检查目录是否存在，再调用 `mkdir()` 创建。检查与创建之间的竞争窗口允许攻击者抢先创建同名目录或符号链接，劫持目录所有权或将应用数据重定向到攻击者控制的位置。

## 根本原因

**位置**: `services/bundlemgr_lite/src/bundle_file_utils.cpp:81`

```cpp
bool BundleFileUtils::MkOwnerDir(const char *rootDir, mode_t mode, uid_t uid, gid_t gid)
{
    if (!IsExistDir(rootDir)) {        // CHECK: 目录不存在
        if (mkdir(rootDir, mode) < 0) { // USE: 创建目录 — 竞争窗口
            return false;
        }
    }
    // 设置目录属主
    if (chown(rootDir, uid, gid) < 0) {
        return false;
    }
    return true;
}
```

**问题**:
1. `IsExistDir()` 与 `mkdir()` 之间存在竞争窗口
2. 攻击者可在窗口内创建同名符号链接指向其控制的目录
3. 随后 `chown()` 将攻击者目录的属主设置为特权用户
4. 即使 `mkdir` 失败（目录已存在），`chown` 仍会执行

## 影响

- 攻击者可劫持应用安装目录
- 通过 `chown` 将非特权目录提升为特权属主
- 可将后续安装的应用数据重定向到攻击者控制位置
- 影响 bundle 安装/更新流程

## 触发条件

1. 攻击者对父目录有写权限（或可预测创建路径）
2. 在 `IsExistDir()` 返回 false 之后、`mkdir()` 执行之前
3. 攻击者抢先创建同名符号链接 → 指向攻击者目录
4. `mkdir` 失败但 `chown` 仍对路径执行（跟随符号链接）

## 修复建议

```cpp
bool BundleFileUtils::MkOwnerDir(const char *rootDir, mode_t mode, uid_t uid, gid_t gid)
{
-   if (!IsExistDir(rootDir)) {
-       if (mkdir(rootDir, mode) < 0) {
-           return false;
-       }
-   }
-   if (chown(rootDir, uid, gid) < 0) {
-       return false;
-   }
+   // 直接尝试创建，避免 TOCTOU
+   if (mkdir(rootDir, mode) < 0 && errno != EEXIST) {
+       return false;
+   }
+   // 使用 lstat 确认非符号链接
+   struct stat st;
+   if (lstat(rootDir, &st) < 0 || !S_ISDIR(st.st_mode)) {
+       return false;
+   }
+   if (lchown(rootDir, uid, gid) < 0) {
+       return false;
+   }
    return true;
}
```
