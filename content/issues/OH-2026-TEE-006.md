## 漏洞概述

`get_share_mem()` 先调用 `check_share_mem_size()` 验证共享内存中所有 `buf_size` 字段之和不超过总缓冲区长度，然后逐个调用 `copy_from_shared_buf()` 从相同共享内存中读取 `buf_size` 并推进指针。由于共享内存由 CA (Client Application) 控制，CA 可在验证通过后修改 `buf_size` 字段为大值，导致 `copy_from_shared_buf` 将指针推进到共享内存边界之外，后续操作访问越界内存。

## 根本原因

**位置**: `crypto_ioctl/crypto_syscall_common.c:149`

```c
static int32_t copy_from_shared_buf(uint64_t *buf_ptr, uint32_t *buf_size, uint8_t **shared_buf)
{
    // 从共享内存读取 buf_size（CA 可在此时修改共享内存）
    if (memcpy_s(buf_size, sizeof(uint32_t), *shared_buf, sizeof(uint32_t)) != EOK) {
        return CRYPTO_ERROR_SECURITY;
    }
    *shared_buf += sizeof(uint32_t);

    if (*buf_size == 0)
        *buf_ptr = 0;
    else
        *buf_ptr = (uint64_t)(uintptr_t)*shared_buf;

    *shared_buf += *buf_size;  // ← 使用从共享内存读取的（可能已被篡改的）大小推进指针
    return CRYPTO_SUCCESS;
}
```

调用上下文：

```c
static int32_t get_share_mem(uint8_t *shared_buf, struct memref_t *get_data, struct crypto_ioctl *ioctl_args)
{
    // CHECK: 验证所有 buf_size 之和 <= buf_len
    bool check = check_share_mem_size(shared_buf, ioctl_args->total_nums, ioctl_args->buf_len);
    // ← CA 在此处修改共享内存中的 buf_size 字段
    // USE: 逐个读取 buf_size 推进指针
    for (uint32_t i = 0; i < ioctl_args->total_nums; i++) {
        ret = copy_from_shared_buf(&get_data[i].buffer, &get_data[i].size, &shared_buf);
    }
}
```

**问题**:
1. `check_share_mem_size` 从共享内存读取所有 size 并验证总和
2. 验证通过后，CA 线程修改共享内存中的 size 字段为更大值
3. `copy_from_shared_buf` 重新读取已被修改的 size
4. 指针推进超出共享内存边界

## 影响

- **越界读取**：`buf_ptr` 指向共享内存之外的 TEE 内核/框架数据
- **信息泄露**：后续操作将越界内存内容返回给 CA
- **任意内核内存读取**：精心构造 size 值可读取 TEE 中任意偏移处的数据

## 触发条件

1. 恶意 CA 通过标准 TEE 接口请求加密操作
2. CA 在共享内存中设置合法的小 `buf_size` 值通过 `check_share_mem_size`
3. 验证完成后，CA 的另一线程立即将 `buf_size` 改为大值
4. TEE 框架从共享内存读取新值并推进指针越界
5. 后续加密操作处理越界数据

## 修复建议

将 size 一次性拷贝到 TEE 本地内存，后续仅使用本地副本：

```c
static int32_t get_share_mem(uint8_t *shared_buf, struct memref_t *get_data, struct crypto_ioctl *ioctl_args)
{
    // 一次性拷贝所有 size 到本地数组
    uint32_t *local_sizes = calloc(ioctl_args->total_nums, sizeof(uint32_t));
    uint8_t *ptr = shared_buf;
    for (uint32_t i = 0; i < ioctl_args->total_nums; i++) {
        memcpy_s(&local_sizes[i], sizeof(uint32_t), ptr, sizeof(uint32_t));
        ptr += sizeof(uint32_t) + local_sizes[i];
    }
    // 验证本地副本
    // 使用本地副本推进指针（不再重读共享内存）
}
```
