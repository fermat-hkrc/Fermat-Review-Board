## 漏洞概述

`copy_from_shared_buffer()` 从共享内存中读取 `buf_size`，然后将该值同时作为 `memcpy_s` 的目标缓冲区容量 (`destMax`) 和拷贝长度 (`count`) 参数。由于 `memcpy_s` 的安全检查本质是 `count <= destMax`，而此处两者相等（均为攻击者控制的同一个值），检查永远通过。若 `buf` 指向的实际缓冲区小于攻击者指定的 `*buf_size`，则发生堆/栈溢出。

## 根本原因

**位置**: `tee_oemkey_driver.c:38`

```c
static int32_t copy_from_shared_buffer(void *buf, uint32_t *buf_size, uint8_t *shared_buf)
{
    if (buf_size == NULL) {
        return -1;
    }

    // 从共享内存读取 size（攻击者控制）
    if (memcpy_s(buf_size, sizeof(uint32_t), shared_buf, sizeof(uint32_t)) != EOK) {
        return -1;
    }

    shared_buf += sizeof(uint32_t);

    // buf_size 同时用作 destMax 和 count → 安全检查被绕过
    if (memcpy_s(buf, *buf_size, shared_buf, *buf_size) != EOK) {
        //          ^^^^^^^^^^^           ^^^^^^^^^^
        //          destMax = *buf_size   count = *buf_size
        //          两者相等 → memcpy_s 检查永远通过
        return -1;
    }
    return 0;
}
```

**问题**:
1. `buf` 的实际分配大小由调用者决定（通常是固定大小的栈/堆缓冲区）
2. `*buf_size` 从攻击者控制的共享内存读取
3. `memcpy_s(buf, *buf_size, src, *buf_size)` 中 destMax == count == 攻击者值
4. memcpy_s 的唯一检查 `count <= destMax` 恒为真
5. 若 `*buf_size` > `buf` 的实际大小 → 缓冲区溢出

## 影响

- **栈溢出**：若 `buf` 是栈上局部变量，可覆盖返回地址实现代码执行
- **堆溢出**：若 `buf` 是堆分配，可覆盖相邻堆元数据/对象
- **TEE 内核代码执行**：在 TEE 可信执行环境中实现任意代码执行，完全突破隔离

## 触发条件

1. 恶意 CA 请求 OEM Key 操作（读取/写入密钥）
2. CA 在共享内存的 size 字段写入大值（如 4096）
3. TEE 框架调用 `copy_from_shared_buffer(local_buf, &size, shared_mem)`
4. `local_buf` 实际大小可能仅 256 字节，但 memcpy_s 拷贝 4096 字节
5. 缓冲区溢出，覆盖栈帧或相邻堆数据

## 修复建议

调用者必须传入 `buf` 的真实容量，在拷贝前验证：

```c
static int32_t copy_from_shared_buffer(void *buf, uint32_t buf_capacity,
                                        uint32_t *buf_size, uint8_t *shared_buf)
{
    if (buf_size == NULL || buf == NULL) {
        return -1;
    }

    if (memcpy_s(buf_size, sizeof(uint32_t), shared_buf, sizeof(uint32_t)) != EOK) {
        return -1;
    }

    shared_buf += sizeof(uint32_t);

    if (*buf_size > buf_capacity) {
        tloge("buf_size %u exceeds capacity %u\n", *buf_size, buf_capacity);
        return -1;
    }

    if (memcpy_s(buf, buf_capacity, shared_buf, *buf_size) != EOK) {
        return -1;
    }
    return 0;
}
```
