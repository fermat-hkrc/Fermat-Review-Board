## 问题概述

`FileUtils.copyFileToDestination()` 和 `FileUtils.saveFile()` 只在正常路径调用 `closeSync()`。文件打开后，如果后续的打开、读取或写入操作抛出异常，`catch` 分支只记录日志，不会关闭已经取得的文件句柄。

本报告统计 3 个独立问题点：复制函数中的源文件句柄、复制函数中的目标文件句柄，以及保存函数中的目标文件句柄。当前源码会把 ImageGeneratorDialog 编译为系统 ABC，但这两个方法在当前组件中没有调用点。因此，当前影响范围受限；该缺陷仍保留为待人工审核的 GitCode Issue。

## 源码证据

### 复制函数的两个句柄只在正常路径关闭

**位置**: `advanced_ui_component/imageGeneratorDialog/source/image_generator_dialog_project/image_generator_dialog/src/main/ets/general/utils/FileUtils.ets:33`

```ts
try {
  let file = fs.openSync(sourceUri, fs.OpenMode.READ_ONLY);
  let readLen = fs.readSync(file.fd, buf, { offset: readSize });
  let destinationDistribute =
    fs.openSync(`${destination}/${file.name}`, fs.OpenMode.READ_WRITE | fs.OpenMode.CREATE);
  while (readLen > 0) {
    fs.writeSync(destinationDistribute.fd, buf);
    readLen = fs.readSync(file.fd, buf, { offset: readSize });
  }
  fs.closeSync(file);
  fs.closeSync(destinationDistribute);
} catch (err) {
  console.error(FileUtils.tag, `copyFileToDestination failed. Code: ${err.code}, message: ${err.message}`);
}
```

以下异常都会绕过关闭操作：

- 源文件打开后，第一次读取失败。
- 源文件打开后，目标文件打开失败。
- 两个文件均打开后，循环中的读取或写入失败。

### 保存函数的句柄也只在正常路径关闭

**位置**: `advanced_ui_component/imageGeneratorDialog/source/image_generator_dialog_project/image_generator_dialog/src/main/ets/general/utils/FileUtils.ets:198`

```ts
try {
  let file = fs.openSync(photoUri, fs.OpenMode.READ_WRITE | fs.OpenMode.CREATE);
  fs.writeSync(file.fd, buffer);
  fs.closeSync(file);
} catch (error) {
  console.error(FileUtils.tag, `saveFile error: ${JSON.stringify(error)}`);
}
```

`openSync()` 成功而 `writeSync()` 抛出异常时，局部变量 `file` 离开作用域前没有显式关闭。

## 影响与限制

- 反复进入异常路径会持续占用当前进程的文件描述符，最终可能使后续文件操作失败。
- 泄漏仅发生在文件已经打开、后续同步操作又抛出异常的情况下。
- `advanced_ui_component/BUILD.gn` 会依赖 `imageGeneratorDialog/interfaces:imageGeneratorDialog`，相关代码属于产品组件，不是测试或示例目录。
- 当前组件内没有找到 `copyFileToDestination()` 或 `saveFile()` 的调用点。尚未确认外部代码能否直接调用打包后的内部工具类。
- 本次只做了源码复核，没有执行故障注入或动态复现。

## 修复建议

把文件对象声明在 `try` 外，并在 `finally` 中分别关闭。关闭前检查对象是否已经创建；单个关闭失败不应阻止另一个句柄被关闭。

```ts
let source: fs.File | undefined;
let destinationFile: fs.File | undefined;
try {
  source = fs.openSync(sourceUri, fs.OpenMode.READ_ONLY);
  destinationFile = fs.openSync(destination, fs.OpenMode.READ_WRITE | fs.OpenMode.CREATE);
  // read and write
} catch (error) {
  console.error(FileUtils.tag, `file operation failed: ${JSON.stringify(error)}`);
} finally {
  if (source) {
    fs.closeSync(source);
  }
  if (destinationFile) {
    fs.closeSync(destinationFile);
  }
}
```
